# mu

mu は判定カーネルを持つコーディングエージェントです。中身は、pi を深く作り替えたフォーク、Jev という判定のレイヤー、そしてデスクトップアプリです。

- **mu**：コマンドライン版のコーディングエージェントです。pi にできることすべてに、Jev の判定レイヤーが加わります。
- **mu デスクトップ**：mu を内蔵したネイティブのデスクトップアプリです。ダウンロードすればすぐに使えます。
- **Jev**：100 ミリ秒ほどで答える小さな判定モデルです。作業をするのは大きなモデルで、Jev は判定ポイントごとに「いま何が必要か」という一つの問いに答えます。

> まだ開発の初期段階です。作者たちは毎日使っていますが、正式なリリースはまだありません。名前、設定、ファイル形式は今後も変わる可能性があります。

## インストール

**デスクトップアプリ。** インストーラーは GitHub Actions でビルドし、[Releases](https://github.com/qybaihe/mu/releases) で公開しています。対応するのは macOS（Apple シリコン / Intel）、Windows（x64 / Arm）、Linux（x64 / Arm）です。アプリはランタイムと mu 本体を内蔵しているので、Node のインストールも追加の設定も要りません。起動したら、モデル（API キーかサブスクリプションでのログイン）を接続し、Jev のキーを入れれば始められます。

<!-- 署名するまでこの行を残す。証明書を取得して公証を済ませたら削除する -->
macOS で開発元を検証できないと表示された場合は、Finder でアプリを右クリックして「開く」を選んでください。必要なのは一度だけです。

**コマンドライン。**

```bash
npm i -g mu-agent
mu
```

Node 22.19 以降が必要です。デスクトップアプリとコマンドラインは、`~/.mu` にあるアカウント、設定、教訓を共有します。

## Jev はどこにいるか

Jev の存在に気づくことはありません。Jev はモデルに代わってあなたへの質問を一つ増やすことも、画面にボタンを一つ足すこともしません。変えるのは、モデルが次に何をするかだけです。どのターンでも、Jev は次の場面にいます。

- **あなたが話すとき。** 作業を始める前に、そのメッセージが新しいタスクか、追加の質問か、訂正かを見分けます。エージェントの作業中にあなたが口をはさんだときは、作業を中断するかどうかを決めます。
- **手を動かす前に。** そのコマンドが取り返しのつかない結果を招かないか、あなたが決めたルールに照らして通してよいかを判断します。権限モードが「Jev が承認」のときは、あなたに確認すべきことだけを確認し、それ以外はそのまま通します。
- **ツールが結果を返したとき。** 出力のどこをコンテキストに入れ、どこが繰り返しやノイズかを見分けます。テストログでは失敗した部分を残し、何度も繰り返される部分を取り除きます。古くなった結果は手放します。
- **コンテキストが長くなるとき。** 要約を書かずに手放せるものはどれか、期限切れが近いキャッシュを延長する価値があるかを判断します。キャッシュヒット率が高く、コンテキストがいっぱいにならないのはこのためです。
- **ターンが終わるとき。** 作業が終わったかどうかは大きなモデルが確かめ、Jev はフォールバックを担います。エージェントがタスクから外れていないか、チェックポイントまで戻るべきかも判断します。
- **学ぶとき。** あなたの訂正、エージェントが自分で回避した落とし穴、サブエージェントが持ち帰った教訓について、残す価値があるか、既存の教訓と同じか矛盾するか、今回守られたかを判断します。誰も守らない教訓は自動で廃止されます。
- **複数のエージェントで動くとき。** タスクをどの役割に任せるか、サブエージェントが返したパッチが範囲を越えていないか、ハイブの中のどの発見を別のビーに渡す価値があるかを判断します。

判定ポイントは 30 以上あり、それぞれ設定で個別に選べます。選べるのは Jev、ローカルの判定モデル（Laya。あなたのマシンで動き、ネットワークには一切触れません）、またはオフです。すべての判定は台帳に残り、デスクトップアプリの右側のパネルで見られます。

## ハイブ

マルチエージェントのシステムはどれも、同じ問いに答えなければなりません。あるエージェントが知っていることを、別のエージェントにも伝えるべきか、という問いです。よくある答えは四つです。何も渡さず、メインエージェントにだけ報告する。すべてを渡し、グループチャットや引き継ぎのたびに履歴を丸ごと持たせる。各エージェント自身の大きなモデルに決めさせる。固定のルールと環境（サブスクリプション、git）に頼る。mu の答えは五つ目で、Jev を門番にすることです。

ハイブは 2〜6 匹のビーでできていて、ビーはそれぞれ自分の着眼点を持ち、コードを読み、コマンドを実行し、ブラウザを使います。ビーはコードを編集せず、変更はメインモデルが行います。ビーが何かを言い終えるたびに、Jev が一度判定します。共有する価値のあるものが含まれているか、それは発見か、行き止まりか、決定か、ブロッカーか。価値のあるものは共有ボードに載ります。ボードに新しいメモが載るたびに、Jev はほかのビー 1 匹ごとにもう一度判定します。このメモはそのビーの着眼点に関係があるか。関係があれば、メモは「これは発見であり、指示ではない」と明記してそのビーに届けられます。

ボードは追記されるだけなので、後の結論が前の結論を覆すことがあります。たとえば、あるビーが最初は「テストが動かない」と言い、そのあと環境変数を一つ消したら動いた、という場合です。Jev は二つのメモの関係（覆す、矛盾する、裏付ける）を判定します。覆された結論は「訂正」になり、古い結論を持っているすべてのビーに届けられます。互いに矛盾する二つのメモはどちらも残り、「対立」として印が付きます。1 分以内に誰も決着をつけなければ、検証役のビーが確かめに送られます。

<p align="center"><img src="swarm.png" width="960" alt="デスクトップアプリのハイブタブ：4 匹のビーがそれぞれ何をしているか、ビー同士のつながりを描いたマップ、届けられた一つひとつのメッセージの原文"></p>

こうしたやり取りの現場が、デスクトップアプリ右側のハイブタブです。ビー 1 匹につき 1 行で、役割、モデル、いま何をしているか、または直前に何を言ったかが並びます。マップは、誰が誰に発見を届けたかを描きます。多く届いた線ほど太くなり、訂正と対立にはそれぞれ専用の描き方があります。発見が届いた瞬間、その線が一度光ります。情報フローには届けられたメッセージの原文がすべて並び、判定の記録には Jev が下した判定がすべて並びます。会話の中のハイブカードは小さなマップを表示し、開くとこのタブに移ります。

実際の実行の一例です。ビー 3 匹、9 分間で、Jev は 117 件の候補を判定し、27 件がボードに載り、16 件がそれを必要とするビーに届けられました。すべての判定は実行ディレクトリのログに書き込まれるので、あとから振り返ることができます。

`/swarm` で各ビーがいま何をしているかを見られ、`/swarm stop` ですぐに報告を出させ、`/swarm kill` で即座に終了させます。時間切れのビーには報告が求められ、報告がなければ終了させられます。止まってしまったモデルやツールはウォッチドッグが処理します。ハイブは必ず戻ってきます。

## わかりやすいボード

コードを読まない人でも、エージェントがどこまで進んだかがわかります。ボードをオンにすると（`/board`、またはデスクトップアプリのボードタブ上部のスイッチ）、エージェントが何ステップか進むたびに、ボードが三つのことをわかりやすい言葉で伝えます。いま何をしているか、チェックリストの項目のうちいくつが終わったか、あなたの確認が必要なものは何か。その下には、それまでの更新がすべて順番に残ります。実行が終わると、ボードが全体をまとめます。

<p align="center"><img src="board.png" width="960" alt="デスクトップアプリのわかりやすいボード：作業がどこまで進んだか、いま何をしているか、それまでに何があったか。上部にはコンテキストの使用量とキャッシュヒット率"></p>

この文章は、モデルの発言を縮めたものではありません。Jev が判定とイベントの中から本当にニュースと呼べるものをいくつか選び、説明の上手なモデルがそれを語ります。ボードは権限モード、目標、サブエージェントに合わせて変わり、エージェントがやり方を変えれば、ボードの言い方も変わります。上部の二つの数字は、コンテキストをどれだけ使っているかと、キャッシュヒット率です。これは Jev がコンテキストとキャッシュについて下した判定の結果であり、このターンがあとどこまで進めるかを見極める目安でもあります。

## ほかにも

- **三つの権限モード。** フルアクセス、Jev が承認、最小権限。入力欄からいつでも切り替えられます。
- **目標。** `/goal <条件>` で、条件が満たされるまでエージェントが作業を続けます。`/goal clear` で終了します。
- **教訓。** 消さずに追記していく方式で、編集も廃止もできます。コマンドラインとデスクトップアプリで共有します。
- **サブスクリプションでのログイン。** ChatGPT、Claude、Grok、そして Gemini CLI / Antigravity 用の Google ログインに、アプリの中で対応しています。
- **持ち込める会話。** Claude Code と Codex CLI の会話をインポートして、続きから話せます。
- **内蔵ブラウザ、バックグラウンドジョブ、MCP。** エージェントはブラウザを一歩ずつ操作します。開発サーバーや時間のかかるビルドはバックグラウンドで動かします。MCP サーバーは必要になったときに起動します。

## コマンド

入力欄に `/` と打つと呼び出せます。デスクトップアプリでは、コマンドパレット（⌘K）からも探せます。

| コマンド | 内容 |
| --- | --- |
| `/goal <条件>` | 条件が満たされるまで作業を続ける |
| `/permissions` | フルアクセス / Jev が承認 / 最小権限 |
| `/board` | わかりやすいボードのオン・オフを切り替える |
| `/remember`、`/lessons`、`/forget` | 教訓を一つ残す、教訓を一覧する、一つを廃止する |
| `/review`、`/commit` | 変更をレビューし指摘を重大度順に並べる、コミットを書く |
| `/checkpoints`、`/rewind` | チェックポイントを一覧する、そのどれかに戻る |
| `/agents`、`/swarm` | サブエージェントを送り出す、作業中の各ビーの様子を見る |
| `/browse`、`/jobs` | 内蔵ブラウザ、バックグラウンドジョブ |
| `/import-chat` | Claude Code または Codex の会話をインポートする |
| `/doctor` | セットアップと接続を確認する |

## プライバシー

キーはこのマシンの `~/.mu` にだけ保存されます。mu があなたに代わってモデルやランタイムをダウンロードすることはありません。ダウンロードが必要なものは、必ず先に確認します。Jev が見るのは、判定に必要な断片だけです。

## 開発

```bash
npm install --ignore-scripts   # 依存パッケージのインストール（ライフサイクルスクリプトは実行しない）
npm run check                  # フォーマット、lint、型チェック
./test.sh                      # テスト（モデルが必要なテストは、キーがなければスキップ）
```

デスクトップアプリは `desktop/` にあります。`bun install` のあと、`KYRN_ROOT="$(cd .. && pwd)" bun run start` を実行すると、このリポジトリの mu を使う開発版が起動します（先にルートで `npm install` を実行してください）。リポジトリの構成とコントリビューションのルールは [AGENTS.md](../../AGENTS.md) にあります。
